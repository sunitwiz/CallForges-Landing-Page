A signature is added to the end of the SMS your users send. Saved replies are SMS you write once and insert in any conversation.

Add a signature

  1. Open Settings → Messaging settings → Messaging and find Signatures.
  2. Click Add signature.
  3. Give it a Name and its Text, up to 160 characters.
  4. Choose where it applies: a User, a Number or both. One user on one number; one user on every number, so each user can have their own; or one number, for everyone who sends from it.

One signature is on at a time for each of these: turning one on turns the earlier one off.

Which signature is used

Only one signature is added to an SMS. A signature for the user on that number wins, then the user's own, then the number's. The out-of-hours reply carries the number's signature.

Signatures count toward the length

The signature goes on a new line at the end of the SMS, so it counts toward its characters and the number of parts it goes out as, up to 10. See SMS length and sending rules.

Saved replies

  1. Open Settings → Messaging settings → Saved replies and click Add saved reply.
  2. Give it a Name and its Text, and save it.
  3. In any conversation, click Saved replies under the message box and pick one to insert it. Search by its name or its words.

Who can change them

  • A user whose role has Manage texting settings and saved replies manages every signature and every saved reply.
  • Other users add, edit and delete only their own signatures, on the numbers they can send from, and insert any saved reply.
