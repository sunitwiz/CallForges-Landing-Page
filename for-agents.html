2. Connect an AI tool to your workspace

CallForges has an MCP server. MCP (Model Context Protocol) is the open standard AI tools use to connect to apps. Connect Claude, ChatGPT, Claude Code, Cursor, VS Code or any other MCP client, then ask it about your calls, contacts, campaigns and texts, or have it do the work.

  • Server URL https://api.callforges.com/mcp For Claude.ai, ChatGPT and other apps that sign in.
  • Key URL https://api.callforges.com/mcp/key For a key, in Cursor, VS Code or Claude Code.

You'll find both in the app under Settings → MCP access. You need the "Connect AI tools (MCP)" permission, which an owner or admin gives in Settings → Roles & permissions.

3. Apps that sign in

Claude.ai and ChatGPT sign in with your CallForges account, so they need no key.

  1. In Claude.ai or ChatGPT, add a custom connector.
  2. Paste the Server URL: https://api.callforges.com/mcp
  3. Sign in with CallForges and pick your workspace.

The app then shows under Connected apps in Settings → MCP access. Click Disconnect to cut it off.

4. Tools that use a key

  1. In CallForges, open Settings → MCP access and click Create key.
  2. Name it, pick Read only or Read & write, and choose when it expires.
  3. Copy the key at once: you won't see it again. The app shows a ready-to-paste setup for Claude Code, Cursor and VS Code.

Claude Code

claude mcp add --transport http callforges https://api.callforges.com/mcp/key --header "Authorization: Bearer YOUR_KEY"

Cursor (~/.cursor/mcp.json)

{
  "mcpServers": {
    "callforges": {
      "url": "https://api.callforges.com/mcp/key",
      "headers": { "Authorization": "Bearer YOUR_KEY" }
    }
  }
}

VS Code (.vscode/mcp.json)

{
  "servers": {
    "callforges": {
      "type": "http",
      "url": "https://api.callforges.com/mcp/key",
      "headers": { "Authorization": "Bearer YOUR_KEY" }
    }
  }
}

Click Revoke next to a key to stop it at any time.

5. What an AI tool can do

  • Read only: your calls and their transcripts, contacts, lists, campaigns and their results, phone numbers, call workflows, texts, CRM connections, and your credits, plan and invoices.
  • Read & write can also create and edit contacts, lists and campaigns, draft and publish call workflows, send texts and work your Inbox, log past calls to your CRM and import contacts from it.
  • Only in the app: starting, pausing and stopping a campaign, placing calls, buying or releasing numbers, billing changes, and inviting users or changing roles.

6. You stay in control

  • An AI tool works as you. It sees and does only what your role allows, and a change to your role applies to it at once.
  • CallForges asks the tool to show you a text and get your yes before sending it, and to ask you before it publishes a workflow.
  • Every change an AI tool makes is recorded in Settings → Activity with an MCP badge and the tool's name.
  • Revoke a key or disconnect an app in Settings → MCP access, and it stops working on its next request.
